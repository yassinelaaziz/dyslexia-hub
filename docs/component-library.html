Component List

Base Components

Button

interface ButtonProps {

variant: 'primary' | 'secondary' | 'tertiary' | 'danger';


size: 'small' | 'medium' | 'large';


disabled?: boolean;


loading?: boolean;


icon?: ReactNode;


children: ReactNode;


onClick?: () => void;


}
Accessibility Features:
  • Keyboard navigation (Enter, Space)
  • Focus indicators
  • ARIA labels for icon-only buttons
  • Loading state announcement
Dyslexia-Friendly Design:
  • Large click targets (44px minimum height)
  • Clear visual feedback (hover, active, focus)
  • High contrast colors
  • Minimal text, clear action

Accessibility Features:
  • Label association (for/id)

Dyslexia-Friendly Design:
  • Large input height (48px)

  • Error messages in red with icons
  • High contrast borders

Conclusion

This component library specification provides:

  • Comprehensive Component List: Base, screening, intervention, visualization components
  • Accessibility Features: WCAG 2.1 AA compliance for all components
  • Dyslexia-Friendly Design: Font, spacing, color, layout considerations
  • Theme System: Default, dyslexia, high-contrast themes
  • Component APIs: Clear TypeScript interfaces
  • Documentation Structure: Storybook-style documentation

The component library is ready for implementation with React (web) and future platforms.
