Component Breakdown

Base Components

  • Button (primary, secondary, tertiary)
  • Input (text, number, select, checkbox, radio)
  • Card (for content grouping)
  • Modal (for dialogs)
  • Typography (headings, body, captions)

Screening Components

  • ScreeningQuestion (single question)
  • ScreeningProgress (progress bar)
  • ScreeningResult (results display)
  • SeverityIndicator (visual severity)
  • GamificationElement (stars, badges)

Intervention Components

  • InterventionCard (list item)
  • InterventionFilter (filter controls)
  • InterventionGuide (step-by-step)
  • ProgressTracker (session tracking)
  • EfficacyRating (star display)

Visualization Components

  • BrainModel3D (interactive 3D)
  • BrainModel2D (fallback 2D)
  • AnnotationOverlay (labels)
  • DevelopmentalTimeline (interactive timeline)
  • MilestoneChart (comparison chart)

Accessibility Considerations

Per-Screen Accessibility

All Screens:
  • WCAG 2.1 AA compliance
  • Screen reader compatible
  • Keyboard navigation
  • High contrast mode
  • Dyslexia-friendly fonts
Screen-Specific:
  • Screening: Audio instructions, no time limits
  • Brain Showcase: Keyboard controls for 3D, audio description
  • Timeline: Screen reader description, keyboard navigation
  • Progress: Color + text indicators, celebration sounds

Dyslexia-Friendly Design Choices

Typography:
  • OpenDyslexic font option
  • Increased letter spacing (0.5-1px)
  • Increased line height (1.5-2.0)
  • Larger font sizes (16px base, 24px headings)
Colors:
  • High contrast mode (black on white, or dyslexia palette)
  • Avoid red/green for critical information
  • Use icons + text for clarity
Layout:
  • Minimal clutter
  • Clear visual hierarchy
  • Consistent spacing
  • Generous white space

Conclusion

These wireframes provide:

  • All MVP Screens Covered: 10 screens for 4 core modules
  • Clear User Flows: Primary, secondary, tertiary, quaternary flows
  • Component Breakdown: Reusable components identified
  • Accessibility Integrated: WCAG 2.1 AA, dyslexia-friendly design
  • Age-Appropriate Complexity: Child vs. adult versions

The wireframes inform component library specification and implementation.
