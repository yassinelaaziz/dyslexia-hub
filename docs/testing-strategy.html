Unit Testing

Framework: Jest + React Testing Library Coverage Goals:
  • Core business logic: 90%+
  • Component library: 80%+
  • Services: 85%+
Test Structure: 
packages/core/src/

screening.service.test.ts


intervention.service.test.ts


repositories/


user.repository.test.ts



packages/web/src/


components/


base/


Button.test.tsx


Input.test.tsx

Example Test: 
describe('ScreeningService', () => {

it('should calculate severity correctly', () => {


const service = new ScreeningService();


const scores = { phonological: 30, rapidNaming: 20, visual: 40, workingMemory: 30 };


const severity = service.calculateSeverity(scores);


expect(severity).toBe('severe');


});


});

Integration Testing

Framework: Jest + Supertest (if API testing needed) Coverage Goals:
  • Module interactions: 75%+
  • Data layer: 80%+
Test Structure: 
packages/core/tests/integration/

screening.integration.test.ts


intervention.integration.test.ts


sync.integration.test.ts
Example Test: 
describe('Screening Integration', () => {

it('should save screening result and retrieve it', async () => {


const service = new ScreeningService();


const repository = new LocalScreeningRepository();


const result = await service.assessUser(8, 'en');


await repository.save(result);


const retrieved = await repository.findById(result.id);


expect(retrieved).toEqual(result);


});


});

Accessibility Testing

Framework: axe-core + Jest + Manual Screen Reader Testing Coverage Goals:
  • WCAG 2.1 AA: 100% compliance
  • Screen reader: NVDA, JAWS, VoiceOver tested
Automated Testing: 
import { axe } from 'jest-axe';


describe('Accessibility', () => {


it('should have no axe violations', async () => {


const render = render();


const results = await axe(container);


expect(results).toHaveNoViolations();


});


});
Manual Testing:
  • NVDA (Windows)
  • JAWS (Windows)
  • VoiceOver (macOS)
  • TalkBack (Android)
Checklist:
  • Keyboard navigation works
  • Screen reader announces all content
  • Focus indicators visible
  • Color contrast meets WCAG AA
  • Forms have labels
  • Images have alt text
  • ARIA attributes correct

Manual Testing Procedures

Pre-Release Checklist:
  • [ ] All automated tests pass
  • [ ] Manual accessibility testing (screen readers)
  • [ ] Manual cross-browser testing
  • [ ] Manual mobile testing (iOS, Android)
  • [ ] Performance testing on real devices
  • [ ] Beta testing with target users
Beta Testing Protocol:
  1. Recruit 5-10 users matching Alex persona
  2. Provide testing instructions
  3. Collect feedback via surveys
  4. Analyze feedback and prioritize fixes
  5. Iterate and re-test
