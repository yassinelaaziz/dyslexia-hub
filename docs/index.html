Welcome to the Documentation

This documentation provides comprehensive technical specifications for the Dyslexia Grand Hub application. The Dyslexia Grand Hub is a platform-agnostic, evidence-based application for individuals with dyslexia, educators, and researchers.

The application is built with a monorepo architecture using React, TypeScript, and Tailwind CSS, with a focus on accessibility, offline-first functionality, and cross-platform compatibility.
