Persona Definitions

Persona 1: Individual with Dyslexia (Primary)

Name: Alex Age: 12 years old Profile:
  • Diagnosed with dyslexia at age 8
  • Struggles with reading speed and accuracy
  • Motivated to improve but frustrated with traditional methods
  • Comfortable with technology (tablet, smartphone)
  • Parents supportive but busy
Goals:
  • Improve reading skills
  • Understand why reading is hard
  • Find interventions that work
  • Track progress to stay motivated
Pain Points:
  • Difficulty reading long text (gets tired quickly)
  • Confusing assessment results
  • Too many intervention options, don't know what works
  • Lack of visual feedback on progress
  • Stigma and shame around dyslexia
Tech Proficiency: Moderate (comfortable with apps, needs simple UI) Key Features Needed:
  • Screening with immediate, clear feedback
  • Brain-friendly learning interventions
  • Visual explanations of brain changes
  • Progress tracking with celebrations
  • Dyslexia-friendly interface (fonts, spacing)

Persona 2: Parent/Caregiver

Name: Sarah Age: 38 years old Profile:
  • Mother of Alex (12, dyslexia)
  • Full-time professional, limited time
  • Wants to help but feels overwhelmed by information
  • Has some budget for interventions but wants evidence-based options
Goals:
  • Understand Alex's dyslexia profile
  • Find effective interventions
  • Track Alex's progress
  • Access research to understand dyslexia
Pain Points:
  • Information overload from internet searches
  • Conflicting advice from different sources
  • Cost of professional interventions
  • Uncertainty about what actually works
  • Time constraints for research
Tech Proficiency: High (comfortable with web and mobile apps) Key Features Needed:
  • Assessment tools for Alex
  • Research summaries (not paywalled papers)
  • Intervention recommendations with efficacy ratings
  • Progress tracking dashboard
  • Community support (optional)

Persona 3: Educator/Professional

Name: Dr. Martinez Age: 45 years old Profile:
  • Special education teacher
  • Works with 15-20 dyslexic students
  • Stays current with research but time-constrained
  • Needs tools for classroom use
Goals:
  • Screen students efficiently
  • Recommend appropriate interventions
  • Access research for professional development
  • Track student progress across multiple students
Pain Points:
  • Time constraints for individualized assessment
  • Staying current with research (paywalled papers)
  • Finding appropriate interventions for different profiles
  • Lack of centralized resources
Tech Proficiency: Very High Key Features Needed:
  • Batch screening tools
  • Research repository access
  • Intervention database with efficacy ratings
  • Professional dashboard (future)
  • Export to clinical systems (future)

Persona 4: Researcher

Name: Dr. Chen Age: 32 years old Profile:
  • Postdoctoral researcher in cognitive neuroscience
  • Studies dyslexia interventions
  • Needs access to data and literature
  • Wants to share findings
Goals:
  • Access research claims database
  • Visualize findings
  • Cite papers easily
  • Share research with community
Pain Points:
  • Fragmented literature access
  • Paywalled papers
  • Difficulty sharing findings
  • No centralized data access
Tech Proficiency: Very High Key Features Needed:
  • Research repository explorer
  • Citation tools
  • Visualization capabilities
  • Data export

User Journey Maps

Journey 1: Alex (Individual with Dyslexia) - First-Time Screening

Step 1: Discovery
  • Trigger: Alex hears about app from parent or teacher
  • Action: Downloads app or visits website
  • Pain Point: Worried about assessment difficulty
  • Solution: Clear, welcoming landing page explaining it's not a test, just a check
Step 2: Onboarding
  • Action: Creates profile (age, language, preferences)
  • Pain Point: Reading too much text is tiring
  • Solution: Minimal text, audio instructions, dyslexia-friendly fonts
Step 3: Screening
  • Action: Starts age-appropriate screening (child version)
  • Pain Point: Test anxiety, fear of failure
  • Solution: Gamified screening, no wrong answers, progress bar encouraging
Step 4: Results
  • Action: Receives screening results immediately
  • Pain Point: Confusing technical jargon
  • Solution: Simple language, visual severity indicator, hopeful messaging ("Your brain can change!")
Step 5: Intervention Exploration
  • Action: Browses recommended interventions
  • Pain Point: Too many options, don't know what to choose
  • Solution: Filtered recommendations based on screening results, efficacy ratings clearly shown
Step 6: Intervention Selection
  • Action: Selects intervention (e.g., RAN-IT)
  • Pain Point: Unclear how to start
  • Solution: Step-by-step guide, video tutorial if available
Step 7: Intervention Use
  • Action: Completes first intervention session
  • Pain Point: Boring or difficult
  • Solution: Gamified elements, immediate feedback, celebration on completion
Step 8: Progress Tracking
  • Action: Views progress dashboard
  • Pain Point: Not seeing improvement
  • Solution: Visual progress charts, achievement badges, motivational messages
Step 9: Brain Showcase
  • Action: Explores brain visualization
  • Pain Point: Complex neuroscience is confusing
  • Solution: Age-appropriate explanations, interactive 3D model, "How interventions change your brain"
Step 10: Return Usage
  • Action: Returns to app daily/weekly
  • Pain Point: Losing motivation
  • Solution: Reminders, streak tracking, social features (optional)
Happy Path: Discovery → Onboarding → Screening → Results → Intervention → Progress → Brain Showcase → Daily Use Edge Cases:
  • Screening interrupted: Save progress, resume later
  • Intervention too difficult: Suggest alternative
  • No progress detected: Encouragement, suggest trying different intervention
  • App crashes: Offline data preserved, sync on restart
Key Decision Points:
  • After screening: Which intervention to try?
  • After 2 weeks: Continue or switch intervention?
  • After 1 month: Progress check, celebrate or adjust
Success Criteria:
  • Screening completion rate >70%
  • Intervention adoption rate >50%
  • Return usage within 7 days >30%

Journey 2: Sarah (Parent) - Understanding and Supporting Alex

Step 1: Discovery
  • Trigger: Searching for dyslexia resources online
  • Action: Finds Dyslexia Grand Hub
  • Pain Point: Skeptical about another resource
  • Solution: Clear credibility indicators (research-backed, evidence-based)
Step 2: Registration
  • Action: Creates account for Alex
  • Pain Point: Privacy concerns about child's data
  • Solution: Clear privacy policy, local-first storage, opt-in cloud sync
Step 3: Screening Alex
  • Action: Has Alex complete screening
  • Pain Point: Unsure if screening is accurate
  • Solution: Confidence indicators, comparison to research norms, recommend professional confirmation
Step 4: Reviewing Results
  • Action: Reviews Alex's screening results
  • Pain Point: Doesn't understand the scores
  • Solution: Plain language explanations, what each score means, age comparisons
Step 5: Research Exploration
  • Action: Explores research repository
  • Pain Point: Paywalled papers, technical jargon
  • Solution: Extracted key findings, plain language summaries, free access
Step 6: Intervention Selection
  • Action: Reviews recommended interventions for Alex
  • Pain Point: Which intervention is best for Alex's profile?
  • Solution: Matched to screening results, efficacy ratings, cost/time estimates
Step 7: Monitoring Progress
  • Action: Checks Alex's progress periodically
  • Pain Point: Unclear if intervention is working
  • Solution: Visual progress charts, improvement indicators, suggestions for adjustments
Step 8: Adjusting Approach
  • Action: Decides to try different intervention
  • Pain Point: Guilt about "giving up" on first intervention
  • Solution: Normalized messaging ("Finding the right fit takes time"), celebrate effort
Happy Path: Discovery → Registration → Screening → Results → Research → Intervention → Monitoring → Adjustment Edge Cases:
  • Alex refuses screening: Encourage with gamification, respect autonomy
  • Screening shows severe dyslexia: Provide resources, encourage professional support
  • No progress after 4 weeks: Suggest professional consultation, different intervention approach
  • Financial constraints: Highlight free/low-cost interventions
Key Decision Points:
  • After screening: Seek professional assessment or proceed with app-based interventions?
  • After 4 weeks: Continue current intervention or try different approach?
  • Budget constraints: Prioritize free interventions or invest in paid options?
Success Criteria:
  • Parent satisfaction with screening results >80%
  • Parent confidence in intervention choice >70%
  • Parent returns to check progress >50%

Journey 3: Dr. Martinez (Educator) - Classroom Use

Step 1: Discovery
  • Trigger: Colleague recommendation or professional development
  • Action: Creates professional account
  • Pain Point: Time investment for learning new tool
  • Solution: Quick onboarding, clear value proposition, tutorial videos
Step 2: Student Screening
  • Action: Screens 5 students in class
  • Pain Point: Takes too much time per student
  • Solution: Efficient screening workflow, batch operations (future), save progress
Step 3: Reviewing Results
  • Action: Reviews screening results for all students
  • Pain Point: Individual results hard to compare
  • Solution: Class overview dashboard, comparison charts, severity distribution
Step 4: Intervention Assignment
  • Action: Assigns interventions to students based on profiles
  • Pain Point: Different interventions for different profiles
  • Solution: Auto-recommendations based on screening, group similar profiles
Step 5: Monitoring Class Progress
  • Action: Tracks progress across all students
  • Pain Point: Time-consuming to check each student individually
  • Solution: Class progress dashboard, aggregate metrics, alert for students not progressing
Step 6: Research Access
  • Action: Looks up research on specific interventions
  • Pain Point: Paywalled papers, limited time for research
  • Solution: Research repository with extracted findings, plain language summaries
Step 7: Sharing with Parents
  • Action: Shares progress reports with parents
  • Pain Point: Parents don't understand technical language
  • Solution: Parent-friendly reports, plain language, visual charts
Happy Path: Discovery → Registration → Batch Screening → Results Review → Intervention Assignment → Progress Monitoring → Research Access → Parent Sharing Edge Cases:
  • Student refuses screening: Respect autonomy, explain benefits, involve parents
  • Class size too large: Prioritize high-risk students, use screening as tool not mandate
  • Student not progressing: Suggest professional referral, different intervention approach
  • Parents concerned about data: Explain privacy policy, local storage option
Key Decision Points:
  • Which students to screen first? (High-risk vs. random sample)
  • How to group students for interventions? (Similar profiles vs. mixed)
  • When to involve parents? (All screenings vs. concerning results only)
  • When to refer to professionals? (Severity thresholds, lack of progress)
Success Criteria:
  • Screening time per student <10 minutes
  • Educator satisfaction with intervention recommendations >75%
  • Class progress tracking saves time vs. manual methods

Journey 4: Dr. Chen (Researcher) - Research Access

Step 1: Discovery
  • Trigger: Searching for dyslexia research database
  • Action: Creates researcher account
  • Pain Point: Unclear if database is comprehensive
  • Solution: Database statistics (460 papers, 335 claims), transparency about methodology
Step 2: Search Claims
  • Action: Searches for claims on specific topic (e.g., RAN interventions)
  • Pain Point: Too many results, hard to find relevant ones
  • Solution: Advanced filters (phase, topic, confidence, date), sorting options
Step 3: Reviewing Claims
  • Action: Reviews relevant claims with sources
  • Pain Point: Need to verify original papers
  • Solution: Direct links to open-access papers, citation export, PMID/DOI
Step 4: Exploring Contradictions
  • Action: Looks for contradictory evidence
  • Pain Point: Hard to find conflicting views
  • Solution: Contradiction links, debate sections from Phase 6
Step 5: Data Export
  • Action: Exports claims for analysis
  • Pain Point: Data format incompatible with analysis tools
  • Solution: Multiple export formats (CSV, JSON, BibTeX), structured data
Step 6: Visualization
  • Action: Uses brain showcase for presentation
  • Pain Point: Need high-quality visuals for papers/talks
  • Solution: Downloadable 3D models, high-resolution exports, annotation support
Step 7: Sharing Findings
  • Action: Cites database in paper
  • Pain Point: Need proper citation format
  • Solution: Citation generator (APA, MLA, BibTeX), persistent DOIs for database
Happy Path: Discovery → Registration → Search → Review → Contradictions → Export → Visualization → Citation Edge Cases:
  • Claim not found: Suggest similar topics, broaden search
  • Source paywalled: Provide extracted findings, suggest alternatives
  • Data format issues: Provide multiple export options, custom format support
  • Citation needed for database: Provide database DOI, citation generator
Key Decision Points:
  • Which claims to include in literature review? (Confidence threshold, relevance)
  • How to handle contradictory evidence? (Present both sides, note controversy)
  • Which data to export? (All claims vs. filtered subset)
  • How to cite database? (Cite specific claims vs. database as source)
Success Criteria:
  • Search finds relevant claims >90% of time
  • Claim accuracy vs. original papers >95%
  • Export formats compatible with analysis tools >80%

Pain Points and Solutions Summary

Common Pain Points Across Personas

1. Information Overload
  • Solution: Curated pathways, progressive disclosure, clear CTAs
2. Technical Jargon
  • Solution: Plain language, glossary, visual explanations
3. Uncertainty About What Works
  • Solution: Efficacy ratings, evidence-based recommendations, confidence indicators
4. Time Constraints
  • Solution: Efficient workflows, batch operations, quick-start guides
5. Privacy Concerns
  • Solution: Local-first storage, clear privacy policy, opt-in cloud sync
6. Motivation/Engagement

Happy Paths and Edge Cases

Happy Path Characteristics

Alex: Screening → Intervention → Progress → Brain Showcase → Daily Use Sarah: Registration → Screening → Research → Intervention → Monitoring Dr. Martinez: Registration → Batch Screening → Intervention Assignment → Progress Monitoring Dr. Chen: Search → Review → Export → Visualization → Citation

Common Edge Cases

Technical:
  • App crashes: Offline data preserved, sync on restart
  • Network failure: Offline mode, queue sync
  • Device compatibility: Responsive design, progressive enhancement
User Behavior:
  • Abandon screening: Save progress, email reminder
  • Refuse intervention: Suggest alternatives, respect autonomy
  • No progress detected: Encouragement, suggest different approach
  • Data loss concern: Backup/export options, clear retention policy
Content:
  • Intervention not available for age: Filter options, suggest alternatives
  • Research claim outdated: Version tracking, update notifications
  • Contradictory evidence: Present both sides, note controversy

Key Decision Points

Screening Phase

  • Age appropriateness: Child vs. adult screening
  • Severity threshold: When to recommend professional help
  • Confidence level: How to present uncertainty in results

Intervention Phase

  • Selection criteria: Which intervention to try first
  • Duration: How long to try before switching
  • Adjustment: When to modify intervention approach

Progress Phase

  • Success metrics: What constitutes progress
  • Celebration triggers: When to celebrate achievements
  • Intervention change: When to switch interventions

Research Phase

  • Relevance threshold: Which claims to include
  • Contradiction handling: How to present conflicting evidence
  • Citation format: How to cite database claims
