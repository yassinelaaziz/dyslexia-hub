Dyslexia Grand Hub - Development Plan

Version: 1.0 Date: 2026-10-31 Author: Senior Tech Lead (Devin) Status: Development Planning Phase - Complete

Sprint Breakdown (12-Week MVP Timeline)

Sprint 1-2: Foundation (Weeks 1-2)

Objectives:
  • Set up monorepo structure
  • Implement core business logic (domain models, services, repositories)
  • Set up build tooling (Vite, TypeScript, ESLint, Prettier)
  • Set up testing framework (Jest, React Testing Library)
Tasks:
  • Initialize monorepo with npm workspaces
  • Create packages/core, packages/web, packages/components
  • Implement domain models (User, ScreeningResult, Intervention, Claim)
  • Implement repository interfaces
  • Implement domain services (ScreeningService, InterventionService)
  • Set up Vite build configuration
  • Configure TypeScript (base and package-specific)
  • Configure ESLint and Prettier
  • Set up Jest and React Testing Library
  • Create initial component library (Button, Input, Card)
Deliverables:
  • Working monorepo structure
  • Core business logic implemented
  • Build and test tooling configured
  • Base component library
Success Criteria:
  • All packages build successfully
  • Core services have unit tests
  • Component library renders in Storybook

Sprint 3-4: Screening Module (Weeks 3-4)

Objectives:
  • Implement screening logic
  • Create child-friendly screening UI
  • Create adult screening UI
  • Implement offline storage for screening results
Tasks:
  • Implement screening algorithm (multi-domain assessment)
  • Create ScreeningQuestion component
  • Create ScreeningProgress component
  • Create ScreeningResult component
  • Create SeverityIndicator component
  • Implement IndexedDB storage for screening results
  • Create screening pages (child and adult versions)
  • Implement accessibility (screen reader, keyboard nav)
  • Implement dyslexia-friendly design (fonts, spacing)
Deliverables:
  • Functional screening module
  • Child and adult screening flows
  • Offline screening result storage
  • Accessibility audit passed
Success Criteria:
  • Screening completes in <10 minutes
  • Results saved to IndexedDB
  • WCAG 2.1 AA compliance
  • Dyslexia-friendly design validated

Sprint 5-6: Intervention Explorer (Weeks 5-6)

Objectives:
  • Implement intervention database (from research repository)
  • Create intervention search and filter
  • Implement efficacy ratings display
  • Create intervention guides
Tasks:
  • Parse research repository for intervention data
  • Implement InterventionService
  • Create InterventionCard component
  • Create InterventionFilter component
  • Create InterventionGuide component
  • Create EfficacyRating component
  • Implement search and filter logic
  • Create intervention explorer page
  • Cache intervention data in IndexedDB
Deliverables:
  • Functional intervention explorer
  • Search and filter working
  • Intervention guides displayed
  • Offline intervention data cached
Success Criteria:
  • Search returns relevant results
  • Filters work correctly
  • Efficacy ratings displayed
  • Data cached offline

Sprint 7-8: Brain Showcase (Weeks 7-8)

Objectives:
  • Implement 3D brain visualization
  • Annotate key brain regions
  • Create before/after intervention animations
  • Implement fallback 2D visualization
Tasks:
  • Set up Three.js and React Three Fiber
  • Create 3D brain model (or load existing model)
  • Implement BrainModel3D component
  • Implement BrainModel2D component (fallback)
  • Create AnnotationOverlay component
  • Implement region selection logic
  • Create before/after animation
  • Implement keyboard controls for 3D
  • Add audio description option
  • Performance optimization (lazy loading, LOD)
Deliverables:
  • Interactive 3D brain model
  • Region annotations
  • Before/after animations
  • 2D fallback
  • Keyboard controls
  • Accessibility audit passed
Success Criteria:
  • 3D model loads in <3 seconds
  • Keyboard controls work
  • Fallback to 2D on low-end devices
  • Screen reader compatible

Sprint 9-10: Developmental Display (Weeks 9-10)

Objectives:
  • Implement interactive timeline
  • Create milestone comparison charts
  • Add intervention impact overlays
  • Implement age-appropriate complexity levels
Tasks:
  • Implement DevelopmentalTimelineService
  • Create DevelopmentalTimeline component
  • Create MilestoneChart component
  • Implement timeline interaction (age selection)
  • Add intervention window overlays
  • Create age-appropriate complexity (child vs. adult)
  • Implement keyboard navigation
  • Add screen reader descriptions
Deliverables:
  • Interactive developmental timeline
  • Milestone comparison charts
  • Intervention impact overlays
  • Age-appropriate complexity
  • Accessibility audit passed
Success Criteria:
  • Timeline is interactive (keyboard/mouse)
  • Milestones clearly labeled
  • Intervention windows highlighted
  • Screen reader compatible

Sprint 11-12: Integration and Testing (Weeks 11-12)

Objectives:
  • Integrate all modules
  • Cross-browser testing
  • Mobile responsiveness testing
  • Accessibility audit (comprehensive)
  • Performance optimization
  • Beta testing with target users
  • Bug fixes and polish
Tasks:
  • Integrate screening, interventions, brain showcase, developmental display
  • Create navigation and routing
  • Implement global state management (Zustand)
  • Create home page and navigation
  • Cross-browser testing (Chrome, Firefox, Safari, Edge)
  • Mobile responsiveness testing (iOS, Android)
  • Accessibility audit (axe-core, screen reader testing)
  • Performance optimization (Lighthouse target: 90+)
  • Beta testing with target users (Alex persona focus)
  • Bug fixes and polish
  • PWA configuration (manifest, service worker)
Deliverables:
  • Fully integrated application
  • Cross-browser compatible
  • Mobile responsive
  • WCAG 2.1 AA compliant
  • Performance targets met
  • Beta testing feedback incorporated
  • PWA capabilities
Success Criteria:
  • All modules integrated
  • Passes cross-browser testing
  • Passes mobile testing
  • Passes accessibility audit
  • Lighthouse score >90
  • Beta test feedback positive

Task Dependencies

Critical Path:
  1. Foundation (Sprint 1-2) → All modules
  2. Screening (Sprint 3-4) → Progress tracking (future)
  3. Intervention Explorer (Sprint 5-6) → Brain showcase (independent)
  4. Brain Showcase (Sprint 7-8) → Developmental display (independent)
  5. All modules → Integration (Sprint 11-12)
Parallel Opportunities:
  • Sprint 3-4 and Sprint 5-6 can run in parallel (different developers)
  • Sprint 7-8 and Sprint 9-10 can run in parallel (different developers)

Risk Register

| Risk | Likelihood | Impact | Mitigation |

|------|------------|--------|------------|

| 3D performance issues on low-end devices | High | High | Fallback to 2D, progressive loading, LOD |

| Screening algorithm accuracy uncertain | Medium | High | Validate against professional assessments, add disclaimer |

| Research repository data quality issues | Medium | Medium | Data validation, manual review of critical claims |

| Accessibility not meeting WCAG 2.1 AA | Medium | High | Continuous testing, axe-core integration, expert review |

| Timeline overrun (12 weeks insufficient) | Medium | Medium | Cut non-essential features, prioritize core modules |

| Dyslexia-friendly design not validated | Medium | Medium | User testing with dyslexic individuals, iterate |
