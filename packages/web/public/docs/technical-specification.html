Architecture Overview

Key Principles:
  • Platform-agnostic core (web → mobile → desktop)
  • Framework-agnostic (no lock-in)
  • Language-agnostic (i18n support)
  • Offline-first (local storage, optional cloud sync)
  • Modular (plugin architecture)
Layers:
  1. Presentation Layer (Web/Mobile/Desktop)
  2. UI Component Layer (Component library)
  3. Application Logic Layer (Feature modules)
  4. Core Business Logic (Domain services)
  5. Data Access Layer (Repository pattern)
  6. Data Storage Layer (IndexedDB/SQLite + PostgreSQL optional)

Technology Stack

Web (MVP):
  • React 18+ with TypeScript
  • Tailwind CSS
  • Zustand (state management)
  • Three.js + React Three Fiber (3D visualization)
  • Vite (build tool)
  • Jest + React Testing Library + Playwright (testing)
Monorepo:
  • npm workspaces
  • Shared core library
  • Web application
  • Component library
Mobile (Future): React Native Desktop (Future): Electron or Tauri Backend (Future): Node.js + Express or Python + FastAPI, PostgreSQL

Data Architecture

Local Storage (IndexedDB/SQLite):
  • Users, ScreeningResults, InterventionProgress
  • Interventions, Claims, Sources (cached from research)
  • SyncMetadata
Cloud Storage (PostgreSQL - Optional):
  • User accounts (for sync)
  • Research claims database (centralized)
  • Intervention metadata (updates)
Sync Strategy:
  • Local-first, cloud sync opt-in
  • Background sync when online
  • Conflict resolution: last-write-wins with user prompt

MVP Features

Priority 1 (Essential):
  1. Dyslexia Screening Module (child and adult versions)
  2. Intervention Explorer (search, filter, efficacy ratings)
  3. Brain Showcase (3D visualization with 2D fallback)
  4. Developmental Display (timeline, milestones, intervention windows)
Priority 2 (Post-MVP):
  • Research Repository Explorer
  • Personalized Learning Dashboard
  • Community Forum
Priority 3 (Future):
  • AI-Powered Personal Coach
  • Research Paper Summarizer
  • Professional Dashboard

Quality Assurance

Testing:
  • Unit tests (Jest): 60-90% coverage
  • Integration tests: 75-80% coverage
  • E2E tests (Playwright): Critical user flows
  • Accessibility tests (axe-core): WCAG 2.1 AA compliance
  • Performance tests (Lighthouse): 90+ score
Manual Testing:
  • Screen reader testing (NVDA, JAWS, VoiceOver)
  • Cross-browser testing (Chrome, Firefox, Safari, Edge)
  • Mobile testing (iOS, Android)
  • Beta testing with target users

Deployment

Hosting: Vercel (web), Railway (backend future) CI/CD: GitHub Actions Environments: Development, Preview (PRs), Production (main) Rollback: Vercel rollback or Git revert

Monitoring

Error Tracking: Sentry Performance: Lighthouse CI + RUM Analytics: Plausible (privacy-first, no PII) Uptime: UptimeRobot

Maintenance

Bug Triage: GitHub Issues + priority labels Feature Addition: Roadmap-based process Research Sync: Quarterly updates from repository Dependency Updates: Monthly security, quarterly features Security Audit: Annual Versioning: Semantic versioning (Major.Minor.Patch)

Accessibility

Dyslexia-Specific:
  • OpenDyslexic font option
  • Increased letter spacing (0.5-1px)
  • Increased line height (1.5-2.0)
  • High contrast modes
  • Audio support (text-to-speech)
General (WCAG 2.1 AA):
  • Screen reader compatible
  • Keyboard navigation
  • Focus indicators
  • Error prevention
  • Resizable text
