Dyslexia Grand Hub - Monitoring Plan

Version: 1.0 Date: 2026-10-31 Author: Senior Tech Lead (Devin) Status: Monitoring Phase - Complete

Error Tracking

Tool: Sentry Setup: 
import * as Sentry from '@sentry/react';


Sentry.init({


dsn: process.env.SENTRY_DSN,


environment: process.env.NODE_ENV,


beforeSend(event) {


// Filter out PII


if (event.request) {


delete event.request.cookies;


delete event.request.headers;


}


return event;


},


});
Tracked Errors:
  • JavaScript errors
  • React errors
  • Promise rejections
  • Network errors
  • IndexedDB errors

Performance Monitoring

Tool: Lighthouse CI + Real User Monitoring (RUM) Lighthouse CI:
  • Automated audits on each deployment
  • Performance targets: 90+
  • Accessibility targets: 90+
RUM Metrics:
  • Page load time
  • Time to interactive
  • Largest contentful paint
  • Cumulative layout shift

User Analytics (Privacy-First)

Tool: Plausible or self-hosted Privacy-First Approach:
  • No personal data collection
  • No cookies
  • No user tracking
  • GDPR compliant
  • Opt-in only
Tracked Metrics:
  • Page views (aggregated)
  • Feature usage (aggregated)
  • Screening completion rate (aggregated)
  • Intervention adoption rate (aggregated)
Excluded:
  • User IDs
  • IP addresses
  • User agents
  • Location data

Uptime Monitoring

Tool: UptimeRobot or Pingdom Monitored Endpoints:
  • Website availability
  • API availability (future)
  • Response time
Alert Thresholds:
  • Downtime > 5 minutes
  • Response time > 3 seconds

Alerting Strategy

Alert Channels:
  • Email (development team)
  • Slack (if available)
  • PagerDuty (critical alerts, future)
Alert Thresholds:
  • Error rate > 1%: Email
  • Error rate > 5%: Slack + Email
  • Downtime > 5 minutes: Email
  • Downtime > 30 minutes: Slack + Email

Dashboard Setup

Tools:
  • Sentry dashboard (errors)
  • Vercel analytics (performance)
  • Plausible dashboard (analytics)
  • UptimeRobot dashboard (uptime)
Key Metrics:
  • Error rate (7-day rolling)
  • Page load time (p95)
  • Screening completion rate
  • Intervention adoption rate
  • Uptime percentage

Conclusion

This monitoring plan provides:

  • Error Tracking: Sentry for error capture
  • Performance Monitoring: Lighthouse CI + RUM
  • Privacy-First Analytics: Plausible, no PII
  • Uptime Monitoring: UptimeRobot
  • Alerting Strategy: Threshold-based alerts
  • Dashboard Setup: Centralized metrics
